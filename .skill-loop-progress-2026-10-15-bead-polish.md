## Convergence judgement — stated BEFORE pass 1

`convergence-detection.md` gives three signals: output size shrinking, change
velocity decelerating, content similarity rising. **Output size is calibrated on
code diffs; these beads are prose.** A legitimately verbose bead set will read
as "not converging" on that signal alone and cut the polish short.

So G2 is judged on the two signals that transfer:
- **change velocity decelerating** — net beads mutated per pass
- **round-over-round similarity rising** — how much pass N repeats pass N-1

and **output size is recorded but treated as advisory only**, because a bead
that grows because a Test Plan got stronger is an improvement, not a regression.
This reasoning is recorded here rather than applied quietly at the end.

**Thresholds:** 0.75 weighted score = finalize. 0.90 = diminishing returns, stop.
Floor is 4-6 passes; under 3 is a named beginner mistake.

**Stop conditions** (no others are valid): two consecutive ZERO-CHANGE passes,
thrashing (same lines flipping back and forth), pass cap 8, or quality target met.
